# Integration catalog

Use the [README integration walkthroughs](../README.md#integrations) for provider registration, callbacks and connection steps.
Use the [Cloudflare configuration reference](cloudflare.md#configure-local-secrets) for secret storage.
This catalog links every app definition and existing provider guide without maintaining a second setup procedure.

Use the specific setup guide where available, then the linked definition and source for its key schema, enablement and callback behavior.
The [static integration inventory](porting/inventory/integrations.tsv) records the underlying source paths.
